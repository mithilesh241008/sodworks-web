About This Repository

This repository contains the source code for the official SODWORKS website.

The website represents our studio, our work, our approach to technology and the ideas we’re building towards.

It is developed using:

1.Next.js — Application framework
2.React — User interface
3.GSAP — Animation and interaction
4.Tailwind CSS — Styling
5.TypeScript — Type safety

Running Locally

To run the website on your local machine:

git clone <repository-url>
cd sodworks-web
npm install
npm run dev
